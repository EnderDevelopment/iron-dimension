# Iron Dimension

Iron Dimension is a Minecraft plugin that creates a unique and immersive event where players are transported to a giant iron dimension filled with challenges and puzzles. This plugin is designed for Minecraft Bedrock Edition and adds a new layer of adventure and exploration to your server.

## Install

1. Download the plugin JAR file from the releases section of the GitHub repository.
2. Place the JAR file in the `plugins` folder of your Minecraft server.
3. Restart your server to load the plugin.

## Use

1. Ensure the plugin is installed and the server is running.
2. Use the command `/startpigevent` to start the Iron Dimension event.
3. Players will be teleported to the Iron Dimension, where they must navigate through a series of challenges and puzzles to find their way out.
